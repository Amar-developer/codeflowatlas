# Interview and resume evidence

For each completed feature, prepare an explanation of its user problem, design choice, alternatives, failure mode, scaling boundary, consistency guarantee, bottleneck, and security controls. Useful discussions include why a queue or Kafka was chosen, how traces distinguish application and database latency, what blocking I/O does in an async endpoint, how analyzer uncertainty is reported, and how AI explanations avoid unsupported claims.

Resume statements should describe implemented and verified behavior. Example themes are AST-based API discovery into a language-neutral IR, trace-linked request flow visualization, repeatable load and failure experiments, evidence-backed bottleneck findings, and grounded AI explanations. Include throughput, latency, accuracy, or scale numbers only when the project has stored measurements and reproducible conditions supporting them.
