# Security and trust boundaries

Treat imported repositories, archives, commit metadata, documentation, HTTP responses, and retrieved text as untrusted input. Main threats are path traversal, archive bombs, unsafe code execution, SSRF, credential leakage, prompt injection, dependency compromise, and cross-project data exposure.

Controls include archive validation, bounded scanning, non-root isolated workers, read-only source mounts where possible, CPU/memory/time limits, egress restrictions, outbound allowlists, authentication, project-level authorization, audit logs, secret scanning, and separation of data from AI instructions. Runtime target execution occurs only in a container or equivalent sandbox with explicit resource and network policy. Traffic and faults require environment labels and target allowlists. The assistant never executes commands suggested by repository content.

Runtime test targets always use a new disposable database and synthetic seed data. CodeFlowAtlas must not request or accept an imported application's original or production database URL, credentials, dump, or real customer records for test setup. Validate schema from supported source models, migrations, or fixtures; AI-generated schema and data are proposals that must pass target startup and contract checks. Unsupported setup stays source-only. Test doubles replace supported outbound dependencies; default-deny egress prevents a generated journey from contacting real payment, email, or third-party systems.

The AI bot cannot independently choose a new target or widen permissions. Store an immutable approved plan with action allowlist, target identity, network destinations, maximum requests, rate, virtual users, duration, resource limits, synthetic dataset ID, and cleanup policy. Revalidate the plan in the runner before every action and retain an audit trail. Local mode needs a user-installed opt-in runner; a normal browser page has no permission to launch local containers. Hosted execution requires a separately reviewed isolation design.
